Savory Delights is a responsive restaurant website developed using HTML and CSS. It provides information about the restaurant, menu items, food services, and contact details.

🚀 Features

Attractive homepage design

Restaurant introduction

Food menu section

Food images and descriptions

About Us section

Contact information

Responsive design

🛠️ Technologies Used

HTML5

CSS3

📂 Project Structure

Restaurant-Website/
│
├── index.html
├── style.css
├── images/
└── README.md

💻 How to Run the Project

Download or clone the repository.

Open the project folder.

Open index.html in your browser.

Explore the restaurant website.

🎯 Project Objective

The main objective of this project is to create an attractive and user-friendly restaurant website using basic frontend technologies.
